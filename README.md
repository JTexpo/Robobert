# Robobert 🤖

**Robobert** is the official Cyanide & Happiness Discord bot.

Robobert provides a collection of commands and features designed to bring Cyanide & Happiness content and functionality directly into Discord servers.

## Features

* Discord slash commands
* Cyanide & Happiness-related functionality
* Server-based configuration
* Lightweight JavaScript implementation

## Requirements

* Node.js
* A Discord application and bot token
* The appropriate Discord bot permissions

## Installation

Clone the repository:

```bash
git clone https://github.com/JTexpo/Robobert.git
cd Robobert
```

Install dependencies:

```bash
npm install
```

Configure the bot using the appropriate configuration/environment variables, then start the application:

```bash
node index.js
```

> **Important:** Never commit your Discord bot token, API keys, or other credentials to the repository.
